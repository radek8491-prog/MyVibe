MY VIBE – kompletní samostatný web

Soubor index.html obsahuje HTML, CSS, JavaScript a vložené obrázky.
Pro GitHub Pages nahrajte index.html do kořenové složky repozitáře a zapněte Pages (Deploy from a branch, main, /root).

Formulář je nastaven pro příjem přes FormSubmit; doručování vyžaduje potvrzení aktivačního e-mailu a reálný test.
Statistika stahování závisí na dostupnosti veřejného GitHub API a vydaných APK; číslo Google Play neobsahuje.
